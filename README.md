# Nishtha & Akshay — wedding invitation (1a)

Upload **every file in this folder** to its own GitHub repository (no subfolders —
all files sit side by side, which is what GitHub Pages needs).

1. github.com → **+ → New repository** → name it → **Public** → Create.
2. **Add file → Upload files** → select all the files in this folder → drag them in → **Commit changes**.
3. **Settings → Pages** → Deploy from a branch → `main` / `(root)` → Save.
4. Your link appears after a minute: `https://USERNAME.github.io/REPO-NAME/`
5. For the WhatsApp preview image, open `index.html`, and change `og:image` to
   `https://USERNAME.github.io/REPO-NAME/preview.jpg`.

**To change any wording, date, venue or name:** edit `details.js`.
**To change a picture or the song:** upload a replacement with the same file name.
